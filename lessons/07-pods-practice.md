# Заняття 7. Практична робота: створення й управління Pod-ами

**Формат:** практичне, 4 аудиторні години. **Максимум:** 20 балів.

## Завдання

Створити Pod із YAML-маніфесту, додати мітку та обмеження ресурсів, перевірити його розміщення і стан, а потім зібрати докази для діагностики змодельованої помилки.

## Хід роботи

1. Створити у виданому namespace `pod.yaml` для узгодженого вебобразу. Задати label, requests для CPU/RAM та безпечний memory limit.
2. Застосувати маніфест і перевірити результат командами `kubectl get pod -o wide`, `kubectl get pod --show-labels`.
3. Перевірити журнали та події через `kubectl logs` і `kubectl describe`.
4. Викладач надає один сценарій помилки: неправильний тег образу або невалідний ресурсний параметр. Внести контрольовану зміну, зафіксувати діагностичний вивід, відновити робочий маніфест і підтвердити `Running`.
5. Видалити Pod і пояснити, чому без контролера він не створиться повторно.

Не створюйте штучно проблеми в системних namespace або на вузлах. Не перевищуйте видані квоти й не перевіряйте доступність чужих ресурсів.

## Звіт

Здати YAML, вивід стану й міток, один фрагмент діагностики та коротке пояснення, як було знайдено і виправлено проблему.

## Критерії оцінювання

| Критерій | Бали |
|---|---:|
| Валідний Pod-маніфест із заданим образом | 5 |
| Label та ресурсні requests/limits налаштовані коректно | 4 |
| Перевірені стан, розміщення та журнали | 4 |
| Помилка діагностована й виправлена за доказами | 5 |
| Безпечне очищення та зрозумілий звіт | 2 |
| **Разом** | **20** |
