# Заняття 5. Практична робота: перший додаток у Kubernetes

**Формат:** практичне, 4 аудиторні години. **Максимум:** 20 балів.

## Завдання

У власному namespace розгорнути вебзастосунок з доступного registry, перевірити його стан, надати доступ усередині кластера за допомогою Service, продемонструвати масштабування та безпечне очищення ресурсів.

## Передумови

- Кластер готовий, вузли `Ready`.
- Викладач надав namespace та kubeconfig із правами лише на потрібні ресурси.
- Образ доступний для вузлів кластера. Для приватного registry викладач заздалегідь налаштовує `imagePullSecret`; секрети не додаються до Git.

## Хід роботи

1. Створити `Deployment` на основі погодженого тестового образу (наприклад, `nginx:stable`) із двома репліками.
2. Перевірити створення ReplicaSet і Pod-ів. Зафіксувати призначення Pod-ів через `kubectl get pods -o wide`.
3. Створити `Service` типу `ClusterIP` на порт застосунку.
4. Перевірити доступність із тимчасового тестового Pod або через узгоджений викладачем спосіб. Не використовувати `NodePort` чи зовнішній LoadBalancer без дозволу.
5. Масштабувати Deployment до трьох реплік, перевірити результат і повернути до двох.
6. Переглянути події/опис ресурсу принаймні для одного Pod-а.
7. Видалити створені ресурси після демонстрації.

Контрольні команди:

```bash
kubectl get deploy,rs,pods,svc
kubectl get pods -o wide
kubectl describe deployment <deployment-name>
kubectl scale deployment <deployment-name> --replicas=3
```

Назви ресурсів курсант обирає самостійно. Маніфести мають містити тільки namespace, виданий викладачем.

## Звіт

Здати Deployment і Service маніфести, вивід `kubectl get deploy,rs,pods,svc`, короткий опис перевірки доступності й пояснення, чому змінювалася кількість Pod-ів після scale.
